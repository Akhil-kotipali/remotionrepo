# PRODUCTION WORKFLOW: IDEA TO FINISHED MP4

This document defines the standard end-to-end production workflow for creating high-retention vertical videos using the autonomous AI director or external Claude ZIP packages.

---

## 1. End-to-End Production Lifecycle

```
[Raw Idea / Narrative Prompt]
             │
             ▼
[Stage 1: AI Creative Direction]
  - Pacing & Narrative Retention Architecture (>70% Stayed Rate)
  - Color Palette Selection
  - Imperceptible Seamless Loop Design (>75% Watch Duration)
             │
             ▼
[Stage 2: Kinetic Timeline & Scene Choreography]
  - Multi-scene arrangement using the 5 Scene Primitives
  - Decoupled Character Rig Kinematics & Facial Expressions
  - Camera zoom, pans, and shockwave decays
             │
             ▼
[Stage 3: Neural Voice & Acoustic Sound Design]
  - Neural dialogue synthesis via edge-tts
  - DSP: Silence trimming, room convolution reverb, -1.5 dBFS normalization
  - Spatial sound effects placement (11 cues)
             │
             ▼
[Stage 4: Manifest & Reference Board Generation]
  - asset-manifest.json generation with licensing & requirements
  - ASSET_REFERENCE_BOARD/ and ASSET_ACQUISITION_GUIDE.md authoring
             │
             ▼
[Stage 5: Autonomous ZIP Packaging]
  - Bundles into a single portable package .zip
             │
             ▼
[Stage 6: Ingestion & Rendering via studio.py]
  - Safe ZIP extraction and manifest validation
  - Dynamic props construction (calculateMetadata)
  - Remotion render with ANGLE D3D11 GPU acceleration
  - High-CTR thumbnail capture & production report generation
```

---

## 2. Option A: Autonomous AI Director (One-Command)

Run `scripts/ai_production_director.py` with your creative concept:

```bash
# Step 1: Generate self-contained production package ZIP
python scripts/ai_production_director.py \
  --idea "Your reflection doesn't leave when you do." \
  --output packages/mirror_anomaly_production.zip

# Step 2: Render finished broadcast MP4 and thumbnail
python studio.py package packages/mirror_anomaly_production.zip
```

## 3. Option B: External Claude Package Ingestion

When receiving a production package `.zip` generated by Claude or an external production system:

### 3.1 Verify Package Structure
The ZIP archive should contain:
```
my_production.zip
├── manifest.json              # Master episode & scene definitions
├── audio_schedule.json       # Dialogue script & timestamps (or pre-rendered master audio)
├── asset-manifest.json       # Asset dependency ledger
└── assets/                   # Optional visual plates, models, or SFX
```

### 3.2 Ingest and Render
```bash
python studio.py package packages/claude_production.zip
```

### 3.3 Handling Missing Assets
If the package omits mandatory background plates:
1. `studio.py` halts safely with exit code 1.
2. Review the printed `ASSET_ACQUISITION_GUIDE.md`.
3. Drop the downloaded file into the exact path specified:
   `public/packages/<episode_id>/assets/backgrounds/<filename>`
4. Re-run:
   ```bash
   python studio.py assets <episode_id>
   python studio.py package packages/claude_production.zip
   ```

---

## 4. Quality Control & Post-Render Verification Checklist

Before publishing or delivering final video files:
1. **Duration & Resolution:** Confirm exactly `1080x1920` (9:16 vertical) and requested framerate (`30 fps`).
2. **Audio Levels:** Confirm voiceover is crisp, ambient drone sits at ~20% volume, and dialogue does not clip.
3. **Captions Sync:** Confirm captions match spoken dialogue words with zero desynchronization drift.
4. **Loop Seam:** Inspect frame 0 and frame `totalFrames - 1` to ensure the camera shutter flash dissolves smoothly.
5. **Clean Repository:** Verify that no `.mp4`, `.png`, or `.jpg` files are staged in git:
   ```bash
   git status
   ```
